\begin{frame}[t]
    \frametitle{CAM is Attention}
    \framesubtitle{Derivation}
    \small
    Let's freshen up: \\
    Asuming $\mathbf{F}_\ell \in \mathbb{R}^{p_\ell\times d_\ell}$ a reshaping of $\mathbf{F}_\ell$, and 
    $\mathbf{q}_\ell\in\mathbb{R}^{d_\ell}$ the \Th{CLS} token\footnotemark.\\
    \footnotetext[3]{\tiny{$p$ relates to $width\times height$. Spatial dimension}}
    \pause
    Attention is defined as:
    \begin{equation}
        \mathbf{a} = A\tran = \softmax \left( \frac{F_\ell \vq_\ell}{\sqrt{d_\ell}} \right).
    \label{eq:cross-attention}
    \end{equation}   
    \pause
    Upon replacing $\mathbf{q}_\ell$ with an arbitrary vector $\alpha\in\mathbb{R}^{d_\ell}$
    \begin{equation}
        \mathbf{a} = h_\ell (F_\ell \mathbf{\alpha}) =
        h_\ell \left( \sum_k \alpha_k \vf_\ell^k \right).
        \label{eq:connection}
    \end{equation}
    With the activation function $h_\ell(\mathbf{x}) = \mbox{softmax}(\mbox{x}/\sqrt{d_\ell})$
\end{frame}

\begin{frame}[t]
    \frametitle{CAM is Attention}
    \framesubtitle{Pooling or Masking}
    \small
    We intend to integrate attention into a model, such that prediction and explanation are linked.\\
    \pause
    \textbf{Cross Attention}:
    \begin{equation}
        \mbox{CA}_\ell(\mathbf{q}_\ell, F_\ell) \defn F\tran \mathbf{a} = F_\ell\tran h_\ell 
        (F_\ell \mathbf{q}_\ell)_{\in \mathbb{R}^d_\ell}
        \label{eq:pooling_1}
    \end{equation}
    \pause
    Which, reshaping the feature matrix as $F_\ell\tran = (\vphi_\ell^1 \dots \vphi_\ell^{p_\ell})$,
    a pooled representation can be expressed, via attention vector $\mathbf{a} = (a_1, \dots, a_{p_\ell})$:
    \begin{equation}
        \mbox{CA}_\ell(\mathbf{q}_\ell, F_\ell)\defn F_\ell\tran\mathbf{a}=\sum_i a_i\vphi_\ell^i.
    \end{equation}
    \pause
    A pooling similar to $\Th{GAP}$, masked in a fashion similar to CAM.

\end{frame}
